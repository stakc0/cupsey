# Cupsey Files

A simple archive grid for selected posts by [@Cupseyy](https://x.com/Cupseyy).

## Run locally

```bash
npm run start
```

Open `http://localhost:3000/`. Posts use the official X embed widget and remain linked to their original X pages.

## Palette

- Aqua: `#73e7f4`
- Yellow: `#f5e470`
- Brown: `#a46635`
- Red: `#c92613`
